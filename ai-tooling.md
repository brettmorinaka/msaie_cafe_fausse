# AI Tooling

**Cursor** was the AI-assisted development tool used for this project. I have not used Cursor before this. Before doing any work for the project, I watched videos and researched how Cursor worked. Not relevant to this project, but I learned about rules, skills, and hooks. Very interesting and useful tools. These will be very helpful in future projects or a professional setting.

## Initial Prompt

Learning that AI tools read and process Markdown efficiently, I converted the project SRS document to a .md file named `project_requirements.mdc` using a free online converter. I pasted that file into this project folder before anything else was created. I prompted Cursor to `Generate an application based on the project_requirements.mdc file`.

## What Worked

After setting up the PostgresSQL database `cafe_fausse` and running the backend and frontend, the website worked. These were created and functioned as specified in the SRS document:
- Front-end was built with React and JSX and back-end was built with Flask and PostgresSQL database.
- All five pages were created and I could navigate between them.
- Menu displayed the proper items, descriptions and prices.
- The About Us page follows the SRS and highlights the owners
- Customers and Reservations tables are created when running the back-end.
- An option for Newsetter signups was created on the Home page and new signups write to the customers table
- New reservations are written to the reservations table with the correct date and time

As I tested out the website, I found a couple operations that did not work exactly as expected or certain areas that I wanted to improve.

## Changes Made

Most of the website functioned properly, but I made some changes to fix certain functions and improve usability:
- Phone number formatting. Although optional, any number of characters was accepted for a phone number. This was fixed to only allow 10 digit phone numbers. (Assisted by Cursor)
- Added placeholders to the name, email, and phone number inputs on the Reservation page. (Assisted by Cursor)
- Scrolling did not work on the Gallery page. Fixed.
- Updated the gallery with provided images and some generated by Gemini.
- The reservations database did not record the number of guests in the reservation. Added the column and recorded num_guests for each reservation.

## Overall Output

Cursor built most of this website and the functionality based on the SRS document. The initial setup of a new project and creating the correct directories is sometimes where I get stuck, so it is amazing that Cursor is able to build so much in a single prompt. Although the a lot of work would have been creating the requirements document, if I had to do that part myself. With AI and tools like Cursor, the code generation is spot on if you can document precise requirements and test/debug key functions after the majority is built.
